## 06 Zero knowledge proofs

Printed source line: docs.redbelly.network: selective disclosure vs ZK

| What the infographic says | Page | Supporting quote |
| --- | --- | --- |
| A ZK proof shows something is true without revealing the data behind it. | [Redbelly docs: Selective disclosure vs zero knowledge](https://docs.redbelly.network/pages/eligibility-sdk/selective-disclosure-vs-zero-knowledge/) | "uses zero-knowledge proofs, allow users to prove a statement is true without revealing any of the underlying data that makes it true" |
| Ask: an app asks one yes or no question (example on the artwork: over 18?). | [Redbelly docs: Selective disclosure vs zero knowledge](https://docs.redbelly.network/pages/eligibility-sdk/selective-disclosure-vs-zero-knowledge/) | "The verifier asks a yes/no question using a query, like “Is the user over 18?”" |
| Prove: your wallet proves it (generates the proof); nothing is revealed. | [Redbelly docs: Selective disclosure vs zero knowledge](https://docs.redbelly.network/pages/eligibility-sdk/selective-disclosure-vs-zero-knowledge/) | "The user's wallet generates a cryptographic proof that they satisfy the query, without revealing their address or any other personal information." |

| Check: a smart contract on Redbelly verifies it. | [Redbelly docs: Selective disclosure vs zero knowledge](https://docs.redbelly.network/pages/eligibility-sdk/selective-disclosure-vs-zero-knowledge/) | "where a smart contract verifies its validity" |
| Artwork: the result is true or false, with no personal data on chain. | [Redbelly docs: Selective disclosure vs zero knowledge](https://docs.redbelly.network/pages/eligibility-sdk/selective-disclosure-vs-zero-knowledge/) | "with no personal data ever being exposed on-chain" |

| Zero knowledge reveals no data, only the proof. | [Redbelly docs: Selective disclosure vs zero knowledge](https://docs.redbelly.network/pages/eligibility-sdk/selective-disclosure-vs-zero-knowledge/) | "In SD, data is revealed. In PBQ, only the proof is shared" |
