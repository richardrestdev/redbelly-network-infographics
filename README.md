| 01 | What is Redbelly? | A public layer 1 blockchain built for tokenising real world assets. |

| 03 | DBFT consensus | Nodes agree on blocks together, with no leader, so blocks are final. |
| 04 | Receptor | Redbelly's identity protocol: lets verified users in, sets rules, proves you qualify. |

| 08 | Compliance aware assets | An asset carries its own rules and every transfer is checked against them. |
| 09 | Identity and accountability | Every participant is known. Nodes that try to cause disagreement leave proof, and disagreement is only possible when 1 in 3 or more nodes are faulty. |
| 10 | Governance | How the Redbelly Community DAO votes today, on its own platform. |
| 11 | Project Acacia | The RBA and DFCRC real money pilot, and Redbelly's part in it. |

## Formats

Every infographic is delivered in all three formats, as PNG and as editable SVG with live text.

| Format | Size | Best for | PNG | SVG |
| --- | --- | --- | --- | --- |
| 16:9 landscape | 1920 × 1080 | Website, X cards, slides | [`png/16x9`](redbelly-explained/png/16x9) | [`svg/16x9`](redbelly-explained/svg/16x9) |
| 4:5 portrait | 1080 × 1350 | Phone feeds | [`png/4x5`](redbelly-explained/png/4x5) | [`svg/4x5`](redbelly-explained/svg/4x5) |
| 1:1 square | 1080 × 1080 | Discord, pins, X | [`png/1x1`](redbelly-explained/png/1x1) | [`svg/1x1`](redbelly-explained/svg/1x1) |

Each file name (for example `10-governance`) exists in all three PNG folders and all three SVG folders.

## Accuracy and sources

- **Supplied resources only.** Every fact on the artwork maps to a page from the task's resource list and a supporting quote in [`SOURCES.md`](redbelly-explained/SOURCES.md), which also lists the exact printed lines each fact supports.
- **Conditions kept.** Where a source attaches a condition to a claim, the condition is printed with it. Infographic 02 shows what each benefit of tokenisation needs (the payment on the same ledger, identity built into the network, a 24/7 market). Infographic 09 says Polygraph's proofs of fraud come from faulty nodes trying to cause disagreement, that disagreement is only possible with 1 in 3 or more faulty nodes, and that removal follows once there is enough proof.
- **Current governance.** Infographic 10 follows the TASK-23 changelog for what has been decided and is in force, and the DAO voting platform for how voting works today. Where the changelog describes Snapshot voting, the voting platform takes priority. Constitution v1.2 and Snapshot rules are not used.
- **Nothing that goes stale or misleads.** Figures that change daily (node counts, TVL, transaction totals) are left out, along with all price talk, investment wording and promises of returns.
- **Dated.** Every infographic prints a "verified" date, so readers know when the facts were checked.

## Verification

Every check runs from a script in `source/tools/` and writes a report to [`verification/`](redbelly-explained/verification/).

| Check | Command | Result (31 Oct 2026) |
| --- | --- | --- |
| Every quote in the source list is still on its live page | `npm run verify` | 101 of 101 quotes found on 28 pages |
| Every printed line traced to a fact and read against its quotes: numbers match, no wider wording (every, all, only, no), hedges kept, every source condition printed | `npm run claims` | 126 of 126 lines and conditions pass |
| Every PNG at the required size; no clipped, overlapping or out-of-bounds text; no text under 11 pt on a 390 pt phone screen in any format, body 12 pt or more on 4:5 and 1:1 | `npm run check` | 33 of 33 layouts pass |
| Every SVG redrawn and compared pixel by pixel with its PNG | `npm run compare` | 33 of 33 match |
| No price talk, investment wording, personal credit, emoji or outdated governance wording | `npm run lint` | Pass |

Full reports: [source check](redbelly-explained/verification/source-check.md) · [claim check](redbelly-explained/verification/claim-check.md) · [layout check](redbelly-explained/verification/layout-check.md) · [SVG check](redbelly-explained/verification/svg-check.md)

## Edit and rebuild

All words come from one content file, so the PNGs, SVGs, gallery and source list never drift apart.

| To change | Edit |
| --- | --- |
| Titles, text, labels and the facts behind them (each fact's quote, the printed lines it supports in `on`, any source condition in `when`) | `source/src/topics.js` |
| The "verified" date | `RX.verified` in `source/src/topics.js` |
| Colours and fonts | `source/src/tokens.css` |
| Diagram layout, per format | `source/src/series.css` |
| Icons (drawn for this series on a 48 unit grid) | `source/src/icons.js` |

```bash
cd redbelly-explained/source
npm install
npx playwright install chromium
npm run build     # PNGs, SVGs, layout check, SVG check, claim check, copy check, gallery and source list
npm run verify    # re-reads every cited page and confirms each quote (needs internet and pdftotext)
```

To edit in a design tool, drag any file from `svg/` into Figma: the text stays editable. For Illustrator or Inkscape, install Be Vietnam Pro and JetBrains Mono from Google Fonts first.

## Design system

- **One series look.** Every infographic shares the same frame: an 11-step series rail with the current topic in red, the series name, number and verified date, a title and a one-sentence answer, one diagram, and a footer with the sources and the DAO logo.
- **Brand.** The series follows the Redbelly DAO Task Board brand kit: deep slate surfaces, one red accent (`#EF5350`), Be Vietnam Pro for words and JetBrains Mono for machine values. The kit asks that DAO material is not presented under the Redbelly Network name, so the DAO mark is used and the Redbelly Network logo is not.
- **Phone first.** Every line of text, labels, sources and dates included, is at least 11 pt when the image fills a 390 pt wide phone held upright, in all three formats (the smallest size in Apple's Human Interface Guidelines, and Material Design's smallest type style). Body text on the 4:5 and 1:1 files is 12 pt or more. The copy was cut to fit: 58 to 92 words per file, header and footer included.
